## 📌 Overview

Health Insights AI (HIA) is a smart and interactive healthcare application that helps users analyze their medical parameters and understand their health condition through visual dashboards and AI-based insights.

---

## 🚀 Features

- 📊 Interactive health analysis dashboard  
- 🧠 Intelligent insights based on user input  
- 📈 Visual metrics (Hemoglobin, TSH, Cholesterol)  
- 📤 File upload support  
- 💬 AI-style chat assistant  
- ⚡ Fast and responsive UI  

---

## 🛠️ Tech Stack

- **Frontend & Backend:** Streamlit  
- **Language:** Python  
- **UI Design:** Custom Streamlit styling  

---

## 🎯 How It Works

1. User inputs health parameters  
2. System analyzes values using logic  
3. Displays results using visual metrics  
4. Provides insights and recommendations  
5. Chat interface allows basic interaction
